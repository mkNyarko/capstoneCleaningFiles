# Capstone Project Initial Data Cleaning Process
 
## Files Included
- Contains R markdown file used for the initial cleaning process
- Also contains two datasets generated from the Rmd
- Contains this Readme file
 
## What the Code Does
- Reads in the FAERS dataset
- Performs basic data cleaning (e.g., renaming columns, filtering)
- Creates summary statistics (e.g., age, gender, responses)
 
## How to Run the Code
1. Download the Rmd into a folder on your pc or mac
2. Visit the US FDA website and download the FAERS 2024 dataset onto your computer
3. Open the Rmd in R studio
4. Modify all file paths in the Rmd so they are consistent with the location of each type of FAERS data/file on your computer
5. Run all codes.

- NB: If the file paths are incorrect, the codes will not run.
